# Nexa POS

Punto de venta en la nube para licorerías y tiendas de barrio.

- `frontend/`: app web (Next.js).
- `backend/`: API (Rust) y base de datos (Supabase).
- `antigravity/`: specs y reportes de los módulos M01 a M24.
- `despliegue/`: Docker, Caddy y guía para el VPS.
- `docs/`: plan de venta y roles.

Cada carpeta conserva su historial de commits original.
